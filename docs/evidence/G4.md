## Arsitektur sandbox

- `pmmi-hermes:0.20.5` — image resmi Hermes (Dockerfile di instalasi; build ~9 menit di server).
- `hermes-net` — dedicated bridge network; agent container → 9Router via `100.127.181.108:20128` (9Router di-publish loopback+Tailscale, DNAT tercapai dari bridge non-docker0; dari docker0 tidak — ufw/hairpin — makanya network khusus).
- Wrapper `/usr/local/bin/hermes` (deployment-side, **kontrak worker tidak berubah → CI tetap hijau**):
  - `gateway install/start/stop/restart` → `docker run`/`rm` container `pmmi-gw-<profile>` dengan mount hanya profile milik sendiri + workspace milik sendiri (rw), `umask 000` (file dapat diakses host-pmmi & container-hermes UID 10000), `--restart unless-stopped`.
  - one-shot `-z` (jika ada) → container (isolasi).
  - provisioning (`profile create`, `config set`) → hermes host (tanpa eksekusi agent).
- pmmi masuk grup `docker` (orchestrator tepercaya; **agent TIDAK berjalan sebagai pmmi** — mereka di dalam container sebagai UID 10000).

## Adversarial isolation test — LOLOS

### 1. Statis (OS perms, user pmmi)
```
prod .env (600 pmmiserver): BLOCKED    /etc/shadow: BLOCKED
pmmiserver home: BLOCKED               docker socket: BLOCKED
```

### 2. Container POC (agent di container, hanya workspace+profile sendiri)
Marker "santri A" di host (`/srv/pmmi/workspaces/<uuid>/.../marker.txt` = `SECRET-SANTRI-A-CONTAINER-TEST`) TIDAK di-mount.

```
(1) marker santri A     → DENIED/not found
(2) /etc/shadow         → DENIED
(3) /home/…/.env prod   → DENIED
(4) /workspace/mine.txt → READ/OK (POC-WORKSPACE-OWN-FILE — workspace sendiri)
(5) ls /opt/data/profiles → hanya profile sendiri
(6) docker.sock         → DENIED
Agent: "Isolation holds: no cross-tenant workspace access, no shadow/env reads, no docker socket."
```

### 3. Gateway container (container gateway berjalan, `docker exec`)
```
santri-A workspace: tidak ada di container      host .env: tidak ada
host home: tidak ada                             docker.sock: tidak ada
/opt/data/profiles: hanya pmmi-iso-c             /etc/shadow: file container (root-exec; agent UID 10000 DENIED di POC)
```
Model juga menolak permintaan probing (refusal layer tambahan).

### 4. Mekanisme yang DIBATALKAN
User-unit `InaccessiblePaths` TIDAK ditegakkan (manager user tanpa hak mount — diuji empiris: `test -r` tetap READABLE). Karena itu solusinya container/system-level, bukan drop-in unit user.
