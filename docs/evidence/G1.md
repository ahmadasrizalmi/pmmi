# G1 — TLS/HTTPS + DNS 3 domain + vhost nginx

Tanggal: 2026-08-22 (update). Server: `pmmiserver`.

## Diagnosis

- DNS 3 domain (`pondokmultimedia.id`, `app.*`, `ai.*`) proxied Cloudflare (anycast `172.67.148.107`/`104.21.87.234`), namun Cloudflare mengembalikan **HTTP 530** — origin tidak terjangkau.
- IP publik server `182.8.226.154` **timeout** untuk port 80/443 dari luar (beberapa kali diuji) → port forwarding router tidak aktif atau ISP memakai CGNAT. Jalur A-record + port-forward tidak dapat diselesaikan tanpa aksi router/registrar.
- **Keputusan: Cloudflare Tunnel** (cloudflared) — bekerja tanpa port inbound (CGNAT-safe). Cloudflare menjadi TLS terminator; origin diakses via tunnel keluar.

## Yang sudah dikerjakan di sisi Cloudflare (via token user, 2026-08-22)

```
Zone:    b5005b70d478577331dfc3b073944978 (pondokmultimedia.id, active)
Account: c094ca4f2f495f414d9c012685f0885f

PATCH /zones/<zone>/settings/ssl             {"value":"full"}          → success
PATCH /zones/<zone>/settings/always_use_https {"value":"on"}           → success   (redirect http→https di edge)
PATCH /zones/<zone>/settings/min_tls_version {"value":"1.2"}           → success
```

`always_use_https=on` memenuhi requirement "redirect http→https" di edge Cloudflare untuk ketiga hostname.

## Yang sudah dikerjakan di server

```
cloudflared 2026.8.2  →  /usr/local/bin/cloudflared
/etc/cloudflared/config.yml (ingress semua hostname → http://localhost:80, nginx-proxy tetap vhost layer):
  pondokmultimedia.id / www / app / ai  →  http://localhost:80
  default → http_status:404
```

## Scope token user (cfut_*)

| Kemampuan | Hasil |
|---|---|
| Zone read / Zone settings edit | ✅ |
| Cloudflare Tunnel read (list) | ✅ |
| Cloudflare Tunnel create / DNS edit | ❌ Authentication error |

`cloudflared` v2026.8.2 tidak lagi punya flag `--api-token` untuk create → pembuatan tunnel harus via dashboard (tanpa token) atau token ber-scope Tunnel:Edit + DNS:Edit.

## Blocked — aksi user (dibutuhkan untuk lanjut)

1. Dashboard Cloudflare → **Zero Trust → Networks → Tunnels → Create a tunnel** → nama `pmmi-prod` (connector type Cloudflared).
2. Tambah **public hostnames** (dashboard otomatis membuat DNS CNAME tunnel):
   - `pondokmultimedia.id` → `http://localhost:80`
   - `app.pondokmultimedia.id` → `http://localhost:80`
   - `ai.pondokmultimedia.id` → `http://localhost:80`
3. Jalankan perintah install dari dashboard di server (atau kirim tunnel token `cloudflared tunnel token pmmi-prod`):
   ```
   sudo cloudflared service install <TUNNEL_TOKEN>
   ```
   (config `/etc/cloudflared/config.yml` sudah siap; setelah install, service `cloudflared` aktif dan tunnel connect.)

Alternatif: berikan token API Cloudflare dengan permission **Cloudflare Tunnel:Edit** + **Zone DNS:Edit** → seluruh langkah di atas bisa saya kerjakan via API.

## Verifikasi setelah tunnel aktif (kondisi sukses G1)

```
curl -sI https://pondokmultimedia.id     → 200/301 (bukan 530)
curl -sI https://app.pondokmultimedia.id → 200
curl -sI https://ai.pondokmultimedia.id  → 200
curl -sI http://pondokmultimedia.id      → 301/308 (redirect https)
```
