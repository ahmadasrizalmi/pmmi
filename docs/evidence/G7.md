### 2. Outbox → notifikasi → delivery

```
outbox_events: admission.submitted → processed=true
notifications: "Pendaftaran PMMI diterima" (admission) → recipient asrizalmi1+pmmitest@gmail.com
               "Applicant baru" (admission_admin) → admin@pmmi.local

notification_deliveries:
EMAIL   | SENT   | e37076a1-0342-45df-a…   ← provider_message_id Resend NYATA (email terkirim)
WHATSAPP| FAILED | WhatsApp provider is disabled
```

### 3. Retry/backoff TERMINAL (live)

```
WHATSAPP|FAILED|attempt_count=5|next_attempt_at=null|"WhatsApp provider is disabled"
→ 5 percobaan (MAX_DELIVERY_ATTEMPTS) dengan exponential backoff, berhenti terminal.
   (Provider disabled → ProviderUnavailable → FAILED + backoff; siklus retry teramati di produksi.)
```
