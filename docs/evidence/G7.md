## DoD #5 — metering ledger LIVE (reservation → settle/reconcile/refund)

```
enrollment.initial_credit | +100
ai.request.reserve        | -5     ← reservasi sebelum request
ai.request.refund         | +5     ← request gagal → refund penuh
reward.granted            | +50
ai.request.reserve        | -5     ← reservasi
ai.request.reconcile_refund| +2    ← settle: usage aktual ~3 kredit → refund sisa
```
